# Mercado Fresco - Gestión de Inventario

Proyecto desarrollado para la asignatura **Desarrollo Frontend II (PFY2202)**.

La aplicación corresponde a un sitio web de gestión de inventario para un supermercado, desarrollado con React y React Router.

## Descripción

Mercado Fresco permite visualizar información general del inventario de un supermercado mediante una interfaz web simple y responsive.

La aplicación cuenta con una página principal para visualizar productos y su disponibilidad, además de páginas informativas accesibles mediante navegación con React Router.

## Funcionalidades

- Visualización de productos del inventario.
- Información de categoría, precio y stock de cada producto.
- Indicadores de productos registrados, unidades disponibles y productos con stock bajo.
- Identificación visual de productos disponibles y con stock bajo.
- Navegación entre distintas páginas mediante React Router.
- Página "Quiénes somos".
- Página "Contáctanos".
- Formulario de contacto con validación de campos.
- Mensaje de confirmación al enviar el formulario.
- Limpieza automática del formulario después del envío.
- Navegación superior e inferior.
- Diseño adaptable a distintos tamaños de pantalla.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- React
- React Router
- Vite
